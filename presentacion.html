El Árbol como un Grafo Especial

En teoría de grafos, un árbol es un grafo dirigido conexo sin ciclos.

En nuestro laboratorio, utilizamos un Árbol AVL (árbol binario auto-balanceable) debido a la relación de jerarquía que existe entre la gravedad de las penas de los delitos.

Los Vértices (Nodos)

En nuestro código, están representados por la clase CaseNode.


class CaseNode {
    constructor(data) {
        this.caseId = data.caseId;       
        this.type = data.type;           
        this.evidence = data.evidence;   
        
        this.gravity = data.gravity;     // ¡Atributo de Peso!
        this.left = null;                // Arista 1
        this.right = null;               // Arista 2
    }
}

Las Aristas y los Pesos

Los atributos this.left y this.right actúan como las aristas direccionadas del grafo. El factor para conectarlas es el peso métrico: gravity.


if (data.gravity < node.gravity) {
    // La arista apunta a la sub-rama izquierda
    node.left = this._insertNode(node.left, data);

} else if (data.gravity > node.gravity) {
    // La arista apunta a la sub-rama derecha
    node.right = this._insertNode(node.right, data);
}

Dinámica: Rotaciones del Grafo

El grafo cambia automáticamente sus aristas en base al 'Factor de Balance' para retener una eficiencia de búsqueda O(log n).


// Algoritmo para balancear subgrafos
rotateRight(y) {
    let x = y.left;       // x será la nueva raíz del subgrafo
    let T2 = x.right;     // Rama huérfana
    
    // Inversión de aristas
    x.right = y;          
    y.left = T2;          
    return x;
}

Recorrido del Grafo

El Reporte Final implementa un algoritmo de travesía: In-Order Traversal.

Esto permite extraer los vértices de menor gravedad a mayor gravedad iterando sobre el grafo profundo.


_inOrder(node, result) {
    if (node) {
        this._inOrder(node.left, result);  // 1. Visitar subgrafo izq
        result.push(node);                 // 2. Extraer vértice raíz
        this._inOrder(node.right, result); // 3. Visitar subgrafo der
    }
}

Conclusiones

  • CaseNode: Nuestro vértice de estado con los datos del crimen.
  • Gravedad (Gravity): El peso algorítmico que define la geometría del grafo.
  • Punteros Left/Right: Las aristas dinámicas manejadas de forma recursiva.
